This is the root dashboard view using NavigationSplitView per D-02 and UI-SPEC window specification.

```swift
import SwiftUI

struct DashboardView: View {
    @State var selectedRecordingId: UUID?
    @Environment(AppDelegate.self) var appDelegate

    var body: some View {
        NavigationSplitView {
            SidebarView(
                historyService: appDelegate.recordingHistoryService,
                selectedRecordingId: $selectedRecordingId
            )
            .frame(minWidth: 200)
        } detail: {
            if let selectedId = selectedRecordingId,
               let item = appDelegate.recordingHistoryService.recordings.first(where: { $0.id == selectedId }) {
                DetailView(item: item, coordinator: appDelegate.recordingCoordinator)
            } else {
                DetailPlaceholderView()
            }
        }
        .frame(minWidth: 800, minHeight: 500)
        .onAppear {
            appDelegate.recordingHistoryService.loadRecordings()
        }
    }
}
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Disk -> UI | RecordingHistoryItem data loaded from local storage displayed in views. Corrupted data could cause UI rendering errors. |
| UI -> NSPasteboard | CopyButton writes user-visible text to system clipboard. Standard macOS API, no elevation risk. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-05 | Denial of service | SidebarView rendering | accept | Very large number of recordings could slow list rendering. SwiftUI List uses lazy loading by default. Acceptable for v1. |
| T-05-06 | Information disclosure | NSPasteboard copy | accept | User explicitly triggers copy of their own data to their own clipboard. Standard macOS behavior. |
| T-05-07 | Elevation of privilege | Dashboard window | accept | Dashboard is read-only browsing. No write operations to filesystem from dashboard views (retry triggers existing services with validated inputs). |
| T-05-08 | Tampering | UserDefaults window frame | accept | Window frame string in UserDefaults could be tampered but only affects window position. No security impact. |
</threat_model>
