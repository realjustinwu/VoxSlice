**1. Create VoxSlice/Views/Dashboard/AudioPlayerViewModel.swift** as an `@Observable @MainActor` class.

This wraps AVPlayer for dashboard playback with time tracking, segment identification, and speed control per D-13, D-14, D-15.

Properties:
- `var isPlaying: Bool = false` -- whether audio is currently playing
- `var currentTime: Double = 0` -- current playback position in seconds
- `var duration: Double = 0` -- total audio duration in seconds
- `var playbackRate: Float = 1.0` -- current speed (0.5, 1.0, 1.5, 2.0)
- `var currentSegmentId: UUID?` -- ID of the segment that contains the current playback time
- `var isLoading: Bool = false` -- whether audio is being loaded
- `var errorMessage: String?` -- error message if audio fails to load or play
- `var audioAvailable: Bool = false` -- whether audio file exists and is loadable

Private:
- `private var player: AVPlayer?`
- `private var timeObserver: Any?` -- periodic time observer token
- `private var playerItemStatusObserver: AnyCancellable?` or NSKeyValueObservation for status
- `private var segments: [Segment] = []` -- reference to transcript segments for current-segment lookup

Initializer:
```swift
init()
```

Methods:

`func loadAudio(for item: RecordingHistoryItem, historyService: RecordingHistoryService)`:
- Call `historyService.recordingURL(for: item)` to get the merged audio file URL
- If URL is nil, set `audioAvailable = false`, `errorMessage = "Audio file not found. The recording may have been moved or deleted."` per UI-SPEC
- If URL exists, create `AVPlayerItem(url: url)` then `AVPlayer(playerItem: playerItem)`
- Set `isLoading = true`
- Observe `playerItem.status` via KVO or Combine:
  - On `.readyToPlay`: set `isLoading = false`, `audioAvailable = true`, read `duration` from `playerItem.duration.seconds`, set `isPlaying = false`
  - On `.failed`: set `isLoading = false`, `audioAvailable = false`, `errorMessage = "Could not play audio. The file may be corrupted."` per UI-SPEC
- Add periodic time observer every 0.25 seconds:
  ```swift
  player?.addPeriodicTimeObserver(forInterval: CMTime(seconds: 0.25, preferredTimescale: 600), queue: .main) { [weak self] time in
      self?.currentTime = time.seconds
      self?.updateCurrentSegment()
  }
  ```
- Store segments from `item.transcript?.segments ?? []`
- Reset: `currentTime = 0`, `currentSegmentId = nil`, `isPlaying = false`

`func play()`:
- `player?.play()`
- `player?.rate = playbackRate` (ensure rate is applied after play)
- `isPlaying = true`

`func pause()`:
- `player?.pause()`
- `isPlaying = false`

`func togglePlayPause()`:
- If playing: pause(). If not playing and audio available: play()

`func seek(to time: Double)`:
- `player?.seek(to: CMTime(seconds: time, preferredTimescale: 600), toleranceBefore: .zero, toleranceAfter: .zero)`
- Update `currentTime = time`
- Call `updateCurrentSegment()`

`func seekToSegment(_ segment: Segment)`:
- Call `seek(to: segment.startTime)`

`func skipForward()`:
- Seek to `min(currentTime + 15, duration)` per D-14

`func skipBackward()`:
- Seek to `max(currentTime - 15, 0)` per D-14

`func setRate(_ rate: Float)`:
- `playbackRate = rate`
- If currently playing, immediately apply: `player?.rate = rate`

`func cleanup()`:
- Remove periodic time observer
- Set `player = nil`
- Called when detail view disappears or recording selection changes

Private method:
`func updateCurrentSegment()`:
- Find the segment where `currentTime >= segment.startTime && currentTime < segment.endTime`
- If found, set `currentSegmentId = segment.id`
- If not found (gap between segments), keep `currentSegmentId` as the last matched segment or nil

Computed properties for UI display:
- `var formattedCurrentTime: String` -- "MM:SS" format
- `var formattedDuration: String` -- "MM:SS" format
- `var formattedSeekPosition: Double` -- normalized 0.0 to 1.0 for slider binding

Deinit: call `cleanup()`

**Important AVPlayer notes:**
- Use `AVPlayer`, not `AVAudioPlayer`. AVPlayer supports seeking, rate changes, and periodic time observation which are all required per D-14/D-15.
- The periodic time observer must use `queue: .main` since we update @Observable properties on @MainActor.
- On `seek(to:)`, use `toleranceBefore: .zero, toleranceAfter: .zero` for precise segment seeking.
- Handle the case where duration is NaN (streaming or unknown) by defaulting to 0.

**1. Create VoxSlice/Views/Dashboard/AudioPlayerView.swift** per D-14 and UI-SPEC audio player specification:

```swift
import SwiftUI

struct AudioPlayerView: View {
    @Bindable var viewModel: AudioPlayerViewModel

    var body: some View {
        VStack(spacing: 8) {
            // Row 1: Transport controls (skip back, play/pause, skip forward)
            HStack(spacing: 16) {
                Spacer()
                Button { viewModel.skipBackward() } label: {
                    Image(systemName: "gobackward.15")
                        .font(.system(size: 16))
                }
                .buttonStyle(.borderless)
                .disabled(!viewModel.audioAvailable)
                .accessibilityLabel("Skip back 15 seconds")

                Button { viewModel.togglePlayPause() } label: {
                    Image(systemName: viewModel.isPlaying ? "pause.fill" : "play.fill")
                        .font(.system(size: 24))
                }
                .buttonStyle(.borderless)
                .disabled(!viewModel.audioAvailable)
                .accessibilityLabel(viewModel.isPlaying ? "Pause" : "Play")

                Button { viewModel.skipForward() } label: {
                    Image(systemName: "goforward.15")
                        .font(.system(size: 16))
                }
                .buttonStyle(.borderless)
                .disabled(!viewModel.audioAvailable)
                .accessibilityLabel("Skip forward 15 seconds")
                Spacer()
            }

            // Row 2: Timeline slider with time labels
            HStack(spacing: 8) {
                Text(viewModel.formattedCurrentTime)
                    .font(.system(size: 13, design: .monospaced))
                    .foregroundStyle(.secondary)
                    .frame(width: 50, alignment: .leading)

                Slider(
                    value: Binding(
                        get: { viewModel.currentTime },
                        set: { viewModel.seek(to: $0) }
                    ),
                    in: 0...max(viewModel.duration, 0.01),
                    onEditingChanged: { _ in }
                )
                .disabled(!viewModel.audioAvailable)
                .accessibilityLabel("Playback position")

                Text(viewModel.formattedDuration)
                    .font(.system(size: 13, design: .monospaced))
                    .foregroundStyle(.secondary)
                    .frame(width: 50, alignment: .trailing)
            }

            // Row 3: Speed controls
            HStack(spacing: 8) {
                ForEach([0.5, 1.0, 1.5, 2.0], id: \.self) { rate in
                    Button {
                        viewModel.setRate(Float(rate))
                    } label: {
                        Text("\(rate, specifier: "%.1f")x")
                            .font(.caption)
                            .fontWeight(.medium)
                            .padding(.horizontal, 8)
                            .padding(.vertical, 4)
                            .background(
                                viewModel.playbackRate == Float(rate)
                                    ? Color.accentColor
                                    : Color.clear
                            )
                            .foregroundStyle(
                                viewModel.playbackRate == Float(rate)
                                    ? .white
                                    : .secondary
                            )
                            .clipShape(RoundedRectangle(cornerRadius: 4))
                    }
                    .buttonStyle(.borderless)
                    .disabled(!viewModel.audioAvailable)
                    .accessibilityLabel("Playback speed \(rate)x")
                }
            }
        }
        .padding(16)
        .background(Color(NSColor.controlBackgroundColor))
        .clipShape(RoundedRectangle(cornerRadius: 8))
    }
}
```

This matches the UI-SPEC player control layout exactly: transport controls centered, slider with monospaced time labels, segmented speed buttons.

```swift
var body: some View {
    ScrollViewReader { proxy in
        ScrollView {
            VStack(alignment: .leading, spacing: 24) {
                // 1. Audio player (replaces the placeholder)
                AudioPlayerView(viewModel: playerViewModel)

                // 2. Transcript section (wired to player)
                transcriptSection

                // 3. Analysis sections
                analysisSections
            }
            .padding(.horizontal, 16)
            .padding(.vertical, 24)
        }
        .onChange(of: playerViewModel.currentSegmentId) { _, newSegmentId in
            // Auto-scroll to highlighted segment per D-15
            if let segmentId = newSegmentId {
                withAnimation(.easeInOut(duration: 0.3)) {
                    proxy.scrollTo(segmentId, anchor: .center)
                }
            }
        }
    }
    .onAppear {
        playerViewModel.loadAudio(for: item, historyService: appDelegate.recordingHistoryService)
    }
    .onDisappear {
        playerViewModel.cleanup()
    }
    .onChange(of: item.id) { _, _ in
        // Reload player when selection changes
        playerViewModel.cleanup()
        playerViewModel.loadAudio(for: item, historyService: appDelegate.recordingHistoryService)
    }
}
```

| Boundary | Description |

| Filesystem -> AVPlayer | Merged audio file loaded from local recordings/ directory. Corrupted audio could cause AVPlayer errors. |
| UI -> AVPlayer | User controls (play/pause/seek/speed) drive AVPlayer state. No input validation risk since controls are bounded. |
