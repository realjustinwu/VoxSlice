Note: The MenuBarExtra `systemImage` binding to recording state provides the icon change per D-05. For the red dot overlay, we need to use a custom image approach since SwiftUI MenuBarExtra does not support overlays directly. Use `.symbolRenderingMode(.palette)` with `.foregroundStyle()` to show a red-tinted icon when recording, or use an `NSStatusItem` approach.

**Better approach for D-05 red dot overlay:** Since `MenuBarExtra` with `.menu` style does not easily support icon overlays, change to use a computed icon that includes the recording indicator:

```swift
// When recording, use "record.circle" (filled red circle) as the icon
// When idle, use "waveform.circle" as the icon
// This provides clear visual distinction per D-05
MenuBarExtra("VoxSlice", systemImage: coordinator.state == .recording ? "record.circle" : "waveform.circle") {
```

Alternatively, use `.menuBarExtraStyle(.window)` which allows a custom SwiftUI view with more flexibility, but `.menu` style is simpler and works for the dropdown approach. Stick with `.menu` style and use `record.circle` for recording state — this is a red circle that clearly indicates recording.

**Modify `VoxSlice/Views/MenuBarView.swift`:**

Replace the entire view with recording-aware implementation:

```swift
import SwiftUI

struct MenuBarView: View {
    @Bindable var coordinator: RecordingCoordinator

    var body: some View {
        // Header
        Text("VoxSlice")
            .font(.headline)

        Divider()

        if coordinator.state == .recording {
            // Recording controls per D-06: elapsed time and Stop button
            HStack {
                Image(systemName: "record.circle")
                    .foregroundStyle(.red)
                Text(coordinator.formattedElapsedTime)
                    .font(.system(.body, design: .monospaced))
            }

            Button("Stop Recording") {
                coordinator.stopRecording()
            }
            .keyboardShortcut("s", modifiers: .command)
        } else {
            // Start recording per D-04: single-click toggle
            Button("Start Recording") {
                coordinator.startRecording()
            }
            .keyboardShortcut("r", modifiers: .command)
        }

        Divider()

        // Settings — uses SettingsLink which responds to cmd+,
        SettingsLink {
            Text("Settings...")
        }
        .keyboardShortcut(",", modifiers: .command)

        // About
        Button("About VoxSlice") {
            NSApplication.shared.orderFrontStandardAboutPanel(
                options: [
                    .applicationName: "VoxSlice",
                    .applicationVersion: "1.0"
                ]
            )
        }

        Divider()

        // Quit
        Button("Quit VoxSlice") {
            NSApplication.shared.terminate(nil)
        }
        .keyboardShortcut("q", modifiers: .command)
    }
}
```

**Key behaviors:**
- Per D-04: Single click on "Start Recording" starts recording (menu bar icon click opens dropdown, then click "Start Recording")
- Per D-05: Menu bar icon changes from `waveform.circle` to `record.circle` (red) when recording
- Per D-06: During recording, dropdown shows elapsed time "MM:SS" and a "Stop Recording" button
- Per D-07: When recording stops, no notification/popup — icon simply reverts to `waveform.circle`, menu shows "Start Recording" again
- Per D-09: Device change notifications posted via `NotificationCenter` from RecordingCoordinator — the menu bar does not need to show these inline; macOS system notifications handle display

**Note on `@Bindable`:** The `coordinator` parameter uses `@Bindable` because `RecordingCoordinator` is `@Observable`. This allows SwiftUI to react to state changes (recording state, elapsed time) automatically.
