Create `VoxSlice/Services/RecordingCoordinator.swift`:

```swift
import Foundation
import AVFoundation
import Combine

@Observable
@MainActor
final class RecordingCoordinator: NSObject {
    // MARK: - Published State (UI binds to these)
    var state: RecordingState = .idle
    var currentRecording: RecordingInfo?
    var elapsedDuration: TimeInterval = 0
    var formattedElapsedTime: String { /* MM:SS format */ }

    // MARK: - Dependencies
    private let audioCaptureService: AudioCaptureService
    private let storageService: StorageService
    private let permissionManager: PermissionManager

    // MARK: - Timer
    private var durationTimer: Timer?

    // MARK: - Notifications
    static let recordingDidStart = Notification.Name("voxslice.recordingDidStart")
    static let recordingDidStop = Notification.Name("voxslice.recordingDidStop")
    static let recordingDidFail = Notification.Name("voxslice.recordingDidFail")
    static let deviceDidChange = Notification.Name("voxslice.deviceDidChange")
}
```

**Methods to implement:**

1. `init(audioCaptureService:AudioCaptureService, storageService:StorageService, permissionManager:PermissionManager)` — Store dependencies, set up notification observers for:
   - `AVAudioApplication.deviceChangeNotification` (or macOS equivalent `NotificationCenter.default` for audio device changes) — call `handleDeviceChange()`
   - AudioCaptureService state change notifications — observe and reflect in coordinator state

2. `startRecording()` — Public API:
   a. Guard: if `state != .idle`, return (already recording or in transition)
   b. Guard: if `!permissionManager.allPermissionsGranted`, post failure notification with "Permissions not granted" and return
   c. Generate timestamp string using `AppConstants.recordingTimestampFormat` ("yyyy-MM-dd_HH-mm-ss") and `DateFormatter`
   d. Get recordings directory URL via `storageService.directoryURL(for: AppConstants.recordingsDir)`
   e. Construct file URLs:
      - Mic: `{recordingsDir}/{timestamp}_mic.m4a`
      - System: `{recordingsDir}/{timestamp}_system.m4a`
      - Metadata: `{recordingsDir}/{timestamp}.json`
   f. Call `audioCaptureService.startRecording(micFileURL:systemFileURL:)` (delegates to AudioCaptureService from Plan 01)
   g. Set `state = .recording`, create `RecordingInfo` with file paths
   h. Start `durationTimer` that fires every 1 second, incrementing `elapsedDuration` and updating `formattedElapsedTime` as "MM:SS"
   i. Post `recordingDidStart` notification

3. `stopRecording()` — Public API:
   a. Guard: if `state != .recording`, return
   b. Set `state = .stopping`
   c. Call `audioCaptureService.stopRecording()` — get back the completed `RecordingInfo`
   d. Stop durationTimer
   e. Save metadata JSON companion file per D-11:
      ```swift
      func saveMetadata(for recording: RecordingInfo) throws {
          let encoder = JSONEncoder()
          encoder.outputFormatting = [.prettyPrinted, .sortedKeys]
          encoder.dateEncodingStrategy = .iso8601
          let data = try encoder.encode(recording)
          let metadataURL = URL(fileURLWithPath: recording.metadataFilePath)
          try data.write(to: metadataURL)
      }
      ```
   f. Update `currentRecording` with completed info
   g. Set `state = .completed`
   h. Post `recordingDidStop` notification

4. `handleDeviceChange(notification:)` — Device change handler:
   a. If not recording, ignore
   b. Extract device name and change type from notification
   c. Create `AudioDeviceChange` record and append to `currentRecording.deviceChanges`
   d. Forward to `audioCaptureService.handleDeviceChange()` for stream reconfiguration
   e. Post `deviceDidChange` notification with device name in userInfo for UI to display per D-09: "Switched to {deviceName}"

5. `formattedElapsedTime` computed property:
   - Format `elapsedDuration` (TimeInterval) as "MM:SS" string
   - Use `Int(elapsedDuration) / 60` for minutes, `Int(elapsedDuration) % 60` for seconds
   - Zero-pad both to 2 digits

6. `deinit` — Clean up timers, notification observers
